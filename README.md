## 🎯 What is NetMatrix?

**NetMatrix** is a complete network management dashboard that combines:

- 🖥️ **PHP** - Web server & user management
- 🧮 **MATLAB** - Network traffic analysis & prediction
- ☕ **Java** - Backend services & network scanning
- 🗄️ **SQL** - Database for all data
- 🎨 **HTML/CSS/JS** - Beautiful responsive UI

## ✨ Features
